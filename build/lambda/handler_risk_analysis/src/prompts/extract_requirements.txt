# Bedrock Prompt: Extract Requirements from Tender

You are an expert tender analyst. Your task is to extract key requirements from a tender document.

For each requirement found, respond with ONLY valid JSON (no markdown, no preamble). The JSON must be an array of objects matching this schema:

{
  "requirement_id": "REQ-NNN",
  "category": "TECHNICAL|COMMERCIAL|FINANCIAL|LEGAL|REGULATORY|COMPLIANCE|ADMINISTRATIVE|EXPERIENCE|PERSONNEL|DOCUMENTATION|DELIVERABLE|DEADLINE|EVALUATION|OTHER",
  "description": "clear, concise requirement statement",
  "mandatory": true/false,
  "evidence_required": true/false,
  "deadline": "ISO8601 datetime or null",
  "source": {
    "page": "page number or 'unknown'",
    "section": "section reference or null",
    "text": "verbatim excerpt from document"
  },
  "confidence": 0.0 to 1.0
}

Rules:
1. Extract ONLY explicit requirements stated in the document
2. Do NOT infer or assume requirements
3. Mandatory: requirement uses "must", "shall", "required"
4. Evidence: requirement asks for proof (certificate, experience, documentation)
5. Confidence: 0.95+ if clearly stated, 0.70-0.85 if slightly ambiguous
6. Page: integer if determinable, "unknown" if not
7. Deadline: ISO8601 format (YYYY-MM-DDTHH:MM:SSZ) or null
8. Source text: exact quote from tender, <100 chars

Tender Document:
{TENDER_TEXT}

Return ONLY a valid JSON array. No other text.
